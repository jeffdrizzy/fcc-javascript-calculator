# JavaScript Calculator

A freeCodeCamp Front End Development Libraries project.

A calculator with chained operations, decimal handling, consecutive-operator rules (last operator wins, except a negative sign), and negative numbers.

## Run

Open `index.html` in a browser, or serve the folder with any static server.

## Tests

The freeCodeCamp test suite is included via `https://cdn.freecodecamp.org/testable-projects-fcc/v1/bundle.js` — select "JavaScript Calculator" in the test dropdown.
